# Фото кейсів

Кожна картка в галереї кейсів (`index.html`, блок `.gal`) має фото
фоном на всю картку: `<img class="case__bg">` першим у `.case__card`.

| Кейс | Файл |
|------|------|
| Комʼюніті, Познань | `community.webp` |
| Легалізація, Познань | `legal.webp` |
| Працевлаштування, Німеччина | `jobs.webp` |
| Студія краси, Познань | `beauty.webp` |

Файли вже чорно-білі, 900px по ширині, webp q70 (30–127 КБ). Оригінали
лежать локально в `фотки на карточки кейсів/` і в git не йдуть.

Прозорість фото (`.case__bg`, `opacity:.2`, при наведенні `.26`) і
маска, що притишує низ картки, стоять у `css/style.css`. Кадр
зсувається через `object-position` у модифікаторі `.case__bg--<назва>`.
