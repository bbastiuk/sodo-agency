# Кадри каналів

Сюди лягають кадри, які трубка на головній ловить як канали.
Імена файлів жорстко зашиті в `CHANNELS` у [`js/main.js`](../../js/main.js).

| Канал | Файл          | Що показує        |
|-------|---------------|-------------------|
| CH 01 | `umi.webp`    | UMI               |
| CH 02 | `razeb.webp`  | Razeb Studio      |
| CH 03 | `street.webp` | Street Barbershop |

Вимоги:

- горизонтальний кадр, орієнтовно 16:9 (трубка обрізає по центру);
- від 1280px по ширині — далі скрипт сам ужимає до 720px;
- `.webp` або `.jpg`, до ~250 КБ;
- колір і контраст не готувати: `prepChannel()` знеколірює кадр,
  заганяє в рожевий люмінофор і гасить кути.

Якщо файла нема — канал тихо випадає зі списку, лишається чистий шум.
Нічого не ламається, порожньої рамки не буде.
