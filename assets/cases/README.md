# Візуальний матеріал кейсів

Галерея кейсів (`index.html`, блок `.gal`) зараз показує тільки текст:
назву, місто, «було» і «результат». Візуального блоку в картці немає
свідомо — краще без картинки, ніж із порожньою рамкою.

Коли будуть реальні матеріали, кожен кейс отримає один кадр:

| Кейс | Файл | Що на кадрі |
|------|------|-------------|
| Комʼюніті, Познань | `community.webp` | Афіша, подія або сторінка спільноти |
| Легалізація, Познань | `legal.webp` | Рекламний креатив або сторінка послуги |
| Працевлаштування, Німеччина | `jobs.webp` | Креатив або кабінет зі статистикою |
| Студія краси, Познань | `beauty.webp` | Роботи студії або оформлення профілю |

Вимоги:

- горизонтальний кадр 16:9 або 3:2, від 1200px по ширині;
- `.webp` або `.jpg`, до ~250 КБ;
- персональні дані й чужі логотипи прибрати.

Як підкласти: у `<li class="case">` одразу після `.case__c` додати

```html
<img class="case__img" src="assets/cases/community.webp" alt="" loading="lazy">
```

і стиль `.case__img{margin-top:18px;border-radius:6px;aspect-ratio:16/9;object-fit:cover}`.
Порядок блоків у картці при цьому лишається: назва й місто → кадр →
«було» → «результат».
