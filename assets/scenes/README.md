# Сцени послуг

Зараз кожна з пʼяти сцен — намальована векторна композиція прямо в
розмітці (`index.html`, блок `.sw__stage`). Це не заглушка-рамка: кожна
показує саме те, про що говорить підпис поруч. Але справжній матеріал
завжди сильніший за схему, тож нижче — що саме треба підкласти, коли
зʼявиться.

| Сцена | Файл | Що має бути на кадрі |
|-------|------|----------------------|
| SMM | `smm-posts.webp` | 3–5 реальних публікацій клієнта сіткою або стосом. Вертикальні, 4:5 або 9:16 |
| Таргет | `ads-creative.webp` | Реальний рекламний креатив (той, що крутився) + скрин статистики без особистих даних |
| Сайти | `site-frame.webp` | Знімок першого екрана сайту, який ми зробили. Горизонтальний, від 1600px |
| Чат-боти | `bot-chat.webp` | Знімок реального діалогу з ботом. Вертикальний. Імена й телефони прибрати |
| Консультації | `audit-notes.webp` | Сторінка плану або аудиту, який ми віддавали клієнту. Суми й назви можна змазати |

Вимоги до всіх:

- `.webp` або `.jpg`, до ~250 КБ;
- колір і контраст не готувати — сцена сама тримає палітру;
- у кадрі не має бути чужих логотипів без дозволу клієнта.

Як підкласти: у потрібній сцені замінити `<svg>` всередині
`<div class="scene">` на `<img src="assets/scenes/…" alt="">`.
Решта розмітки й стилі не змінюються, розмір смуги сталий.

Поки файла немає — лишається намальована композиція. Порожньої рамки
на сайті не буде в жодному разі.
