# Візуал послуг

Малюнків-сцен більше немає. Візуал послуги тепер будується з самого
змісту: рожева папка, а в ній світлі нахилені підписи з рожевою
обвідкою у форматі `[01] НАЗВА — короткий опис`. Пункти змінюються
разом із вибраним табом, розмітка в `index.html`, блок `.sw__box`.

Тобто окреме зображення тут не потрібне — блок повний і без нього.

Якщо колись захочеться додати до послуги реальний кадр (знімок
публікацій, рекламного кабінету, сайту чи діалогу з ботом), місце під
нього — всередині `<article class="svc">`, одразу після `.svc__d`:

```html
<img class="svc__img" src="assets/scenes/instagram.webp" alt="" loading="lazy">
```

і стиль `.svc__img{margin-top:16px;border-radius:10px;border:1.5px solid var(--pink)}`.

Вимоги до кадру: `.webp` або `.jpg`, до ~250 КБ, без чужих логотипів
без дозволу клієнта. Колір не готувати — папка сама тримає палітру.
