# SODO — сайт агенції

Односторінковий сайт digital-агенції **SODO** (SMM, Meta Ads, Google Ads, сайти, чат-боти).
Стек без збірки: **HTML + CSS + vanilla JS**, без бібліотек і CDN.
GitHub Pages: покладіть вміст папки в корінь репозиторію.

Мова — українська.

---

## Артдирекція

Сайт побудований як digital-постер, що розгортається в портфоліо.

- **Палітра:** `#0B0B0C` · `#F2EFEA` · `#F58BB0`.
- **Гарнітури (self-hosted, OFL):** `Unbounded` — дисплейна, `Inter` — текстова.
  Файли в `assets/fonts/`, підключення — `fonts.css`.
- **Перший екран.** Напис SODO займає 88% ширини екрана і є головним графічним
  елементом. Він розрізаний на чотири окремі шари-літери (маска логотипа +
  `clip-path` по реальних проміжках між гліфами), тому фрагменти робіт проходять
  частково перед літерами, частково за ними.
- **Ритм.** Щільний герой → великий кейс → коротка типографічна пауза →
  асиметричний кейс → послуги → стрічка креативів → короткий бренд-блок → фінал.
  Секції навмисно різної висоти, композиції не центровані.

## Матеріали робіт

Реальних клієнтських матеріалів у репозиторії немає, тому **всі роботи — це живі
макети на HTML/CSS**, а не картинки: вікно браузера з сайтом, мобільні екрани,
чат-бот, пошукова видача, рекламні креативи, добірка reels, типографічна айдентика.

Кожен макет має плашку `demo`. Вони масштабуються через **container queries** —
той самий макет виглядає правильно і як фрагмент колажу, і на весь екран,
і на телефоні (перебудовується як справжній адаптивний сайт).

Замінити на реальні матеріали просто: у відповідному `<figure>` поставте
`<img>`/`<video>` замість блоку `.mk` — решта верстки не зміниться.

З попередньої версії лишився **один** 3D-об'єкт (`branding-head.webp`) — як
signature-акцент усередині макета сайту барбершопу. Решта 3D-рендерів більше не
використовується (файли лишились у `assets/images/` — можна видалити).

## Три сцени руху

Власний motion-движок (`js/main.js`): сцени прив'язані до прогресу скролу,
`requestAnimationFrame` вмикається лише коли є рух. Бібліотек немає.

1. **Герой → перший кейс.** Секція `.stage` висотою 215svh із `position: sticky`
   всередині. По прогресу: літери SODO розлітаються з різним запізненням і
   масштабом, фрагменти йдуть у глибину, а центральний макет сайту фізично
   перебудовується — його рамка інтерполюється від місця в композиції (`--slotL/T/W/H`)
   до повного екрана, панель браузера й навігація згортаються, з'являється
   затемнення і підпис кейсу. Одна прокрутка — одна трансформація.
2. **Типографічна пауза.** Три великі рядки рухаються горизонтально з різною
   швидкістю й стискають трекінг — текст змінює структуру під час скролу.
3. **Фінал.** Рожева площина піднімається знизу, а дубль заголовка, обрізаний
   `clip-path` рівно по межі панелі, перефарбовує літери з білих у чорні —
   типографіка «ламає» чорну сторінку.

Плюс: стрічка креативів їде горизонтально від скролу, фрагменти кейсу 02 рухаються
з різною швидкістю, прев'ю послуг перебудовується (новий контент, композиція,
фон і підпис), курсор на desktop показує стан `дивитись`, колаж героя реагує
на курсор із різною глибиною.

**Статичний fallback.** При `prefers-reduced-motion: reduce` сцени вимикаються,
секції стають звичайними блоками, композиція героя лишається такою самою й
без жодного руху. Без JS сайт теж читається повністю.

## Структура

```
index.html            весь контент і макети робіт
css/style.css         токени, мокап-кіт, секції, адаптив, reduced-motion
js/main.js            движок сцен, послуги, меню, форма, курсор, аналітика
assets/fonts/         Unbounded + Inter (woff2, latin + cyrillic)
assets/images/        logo-sodo.webp (маска напису), branding-head.webp (акцент),
                      og-image.jpg, apple-touch-icon.png + невикористані рендери
```

## Що замінити перед публікацією

- [ ] **Адреса сайту** — `https://bbastiuk.github.io/sodo-agency/` у `canonical`,
      `og:url`, JSON-LD.
- [ ] **Контакти:** Telegram `t.me/sodoagency`, Instagram `instagram.com/sodo.agency`,
      пошта `hello@sodo.agency` (перевірте — вона не підтверджена).
- [ ] **Форма.** У `js/main.js` впишіть `FORM_ENDPOINT` (напр. Formspree).
      Поки порожньо — сайт **не вдає успішну відправку**: після валідації показує,
      що форму не підключено, і дає готовий лист (`mailto` з підставленим текстом)
      та Telegram.
- [ ] **Кейси.** `Street Barbershop` — лише публічні показники профілю Booksy
      з приміткою. У `LegalizuYou` і `MS West` рядок «результат» містить «—»:
      впишіть реальні цифри або приберіть рядок. Тексти задач — теж шаблонні.
- [ ] **Макети робіт** — замінити на справжні екрани, креативи й відео
      (див. розділ «Матеріали робіт»).
- [ ] **OG-зображення** `assets/images/og-image.jpg` — на фірмове 1200×630.
- [ ] **Аналітика.** Події вже йдуть у `window.dataLayer` з префіксом `sodo_`.
      Додайте свій сніпет GTM / GA4 / Meta Pixel у `<head>`.

## Доступність і продуктивність

- Один `h1`, послідовні заголовки, skip-link, видимий фокус, `aria-expanded`
  на послугах і кнопці «дивитися кейс», `aria-live` на статусі форми.
- Нічого не сховано лише за hover: наведення дублює те, що доступне кліком і
  з клавіатури.
- Немає горизонтального скролу від 320px до 1280px (перевірено).
- Вага сторінки: шрифти ~150 КБ + два зображення ~85 КБ. Решта «робіт» — верстка.
- `overflow-x: clip` замість `hidden` — щоб sticky-сцени лишались надійними.

## Локальний запуск

```
python -m http.server 8080
```
Далі `http://127.0.0.1:8080/`. Додайте `?debug` — і в консолі з'явиться
`window.__sodo` зі сценами (зручно перевіряти кадри переходу вручну).
