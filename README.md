# SODO Agency — односторінковий сайт

Преміальний односторінковий сайт для бутикової digital-агенції **SODO** (Познань, Польща).
Чистий стек без фреймворків: **HTML5 + CSS3 + Vanilla JS**. Готовий до GitHub Pages без збірки.

Мови: **UA** (основна) / **PL** — перемикач у хедері та футері, вибір зберігається в браузері.

---

## 📁 Структура

```
index.html            # весь сайт (семантика, SEO, OG, JSON-LD, data-i18n, data-track)
css/style.css         # дизайн-система + усі секції + адаптив + reduced-motion
js/main.js            # i18n UA/PL, меню, reveal, курсор, magnetic, parallax, форма, аналітика
assets/
  images/             # 8 фірмових 3D-об'єктів (WebP, з прозорістю) + og-image + apple-touch-icon
  images/source/      # оригінальні PNG-майстри (не використовуються на сайті; для повторного експорту)
  fonts/fonts.css     # @font-face для Benzin (додайте .woff2 — див. нижче)
  icons/favicon.svg   # фавікон
  video/              # (порожня) — за потреби покладіть showreel-постер/відео
```

## 🚀 Публікація на GitHub Pages

1. Створіть репозиторій і завантажте **весь вміст цієї папки в корінь** репозиторію
   (`index.html` має бути в корені, не у вкладеній папці).
2. GitHub → **Settings → Pages**.
3. **Source:** `Deploy from a branch`. **Branch:** `main`, **Folder:** `/ (root)`. Save.
4. Через 1–2 хв сайт буде доступний за адресою
   `https://<ваш-username>.github.io/<назва-репо>/`.

> Нічого встановлювати/білдити не потрібно — це статичний сайт.
> Локально можна відкрити просто подвійним кліком по `index.html`
> (або запустити локальний сервер, напр. `python -m http.server`).

## 🔤 Шрифт Benzin (display)

Benzin **не входить** у репозиторій (комерційна ліцензія). Зараз використовується важкий
системний fallback (Arial Black / Impact), який підтримує кирилицю.

Щоб увімкнути Benzin:
1. Придбайте web-ліцензію та експортуйте `.woff2`.
2. Покладіть файли в `assets/fonts/` з іменами:
   `benzin-medium.woff2`, `benzin-bold.woff2`, `benzin-extrabold.woff2`.
3. Готово — `@font-face` уже налаштований у `assets/fonts/fonts.css`.

(Опційно можна так само підключити локальний **Inter** для основного тексту — інструкція в
`fonts.css`. Зараз використовується системний стек, що швидше.)

## 📊 Аналітика (Meta Pixel / GA4 / GTM)

У `<head>` файлу `index.html` є **закоментований блок** зі сніпетами GTM, GA4 і Meta Pixel —
вставте свої реальні ID (жодних вигаданих ID у коді немає).

Події вже надсилаються у `window.dataLayer` через функцію `track()`. Ключові кнопки мають
`data-track`, тож після підключення GTM ви одразу отримаєте події:

`hero_consultation`, `hero_cases`, `service_meta_ads`, `service_smm`, `service_content`,
`service_branding`, `service_web`, `case_open`, `instagram_click`, `telegram_click`,
`form_submit` (а також `sodo_lead` при успішній відправці форми та `sodo_lang_switch`).

У dataLayer події приходять з префіксом `sodo_` (напр. `sodo_form_submit`).

## 🎨 Дизайн-система (коротко)

- Кольори (CSS-змінні у `:root`, `css/style.css`): фон `#08090B`, темний `#141416`,
  рожевий акцент `#FA9BB6`, текст `#F4F2F3`, другорядний `#8D888C`.
- Пропорція кольору ~70% чорний / 20% світлий / 10% рожевий.
- Типографіка: Benzin (заголовки/цифри) + Inter/системний (текст), fluid `clamp()`.
- Анімації на `transform`/`opacity`, з повагою до `prefers-reduced-motion`.
  Кастомний курсор, magnetic-кнопки та parallax — лише на desktop-мишці.

## 🖼️ Про зображення

8 фірмових 3D-об'єктів оброблені: прибрано фон-шахматку, обрізано поля, зменшено та
конвертовано у **WebP з прозорістю** (усі разом ≈ 0.6 МБ). Оригінальні PNG-майстри лежать у
`assets/images/source/` — якщо захочете переекспортувати з іншими розмірами.
WebP підтримується всіма сучасними браузерами.

## 🔧 Технічні деталі

- Немає зовнішніх залежностей / CDN — сайт повністю self-contained.
- `defer` для JS, `loading="lazy"` для зображень нижче першого екрана,
  `fetchpriority="high"` + `preload` для hero.
- Семантичний HTML, `aria`-атрибути, видимий focus, keyboard-навігація меню, skip-link.
- Немає горизонтального скролу від 320px до 1920px.
