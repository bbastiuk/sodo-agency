# SODO — односторінковий сайт агенції

Односторінковий сайт digital-агенції **SODO** (SMM, Meta Ads, Google Ads, сайти, чат-боти).
Стек без збірки: **HTML + CSS + vanilla JS**, без CDN і зовнішніх залежностей.
Готовий до GitHub Pages: покладіть вміст папки в корінь репозиторію.

Мова інтерфейсу — українська.

---

## Концепція та артдирекція

«SODO — увага, що набуває форми»: перший екран — digital-постер, далі скрол збирає
фрагменти в портфоліо. Подача — сучасний незалежний журнал, перенесений у вебсайт.

- **Палітра:** `#111111` (майже чорний), `#F5F2EE` (теплий білий), `#F58BB0` (рожевий).
  Ритм секцій: темний герой → світлі роботи → темні послуги → світлий процес →
  темна агенція → рожевий екран контакту → темний футер.
- **Гарнітури (дві, self-hosted, OFL):** `Unbounded` — дисплейна (заголовки, назви послуг),
  `Inter` — текстова та службові підписи. Обидві з кирилицею й українськими літерами.
  Файли в `assets/fonts/`, підключення — `assets/fonts/fonts.css`. Benzin більше не потрібен.
- **Деталі:** тонкі лінії, нумерація рубрик `(01)`, дрібні підписи капсом,
  редакторські позначки від руки — inline-SVG (підкреслення в заголовку).

## Три ключові анімації

1. **Вступ.** Рядки H1 виїжджають з-під маски зі зсувом у часі; фрагменти колажу
   стають на місця з різним запізненням; рух курсора дає паралакс за глибиною
   (`data-depth`, лише миша + `pointer: fine`). Без прелоадера — контент доступний одразу.
2. **Перехід до робіт.** Головний кадр колажу відривається у `position: fixed` шар
   (`.morph`) і по прогресу скролу перетікає в плашку першого кейсу: інтерполяція
   прямокутників `from → to` + `object-fit: cover`. Вмикається від 1024px, вимикається
   при `prefers-reduced-motion` — тоді просто звичайна поява зображення.
3. **Фінальний контакт.** Рожева площина розкривається з інсету на весь екран
   (`clip-path` через змінну `--r`, яку JS рахує зі скролу), далі маскою проявляється
   заголовок і форма.

Усе інше — стримано: поява через маску, масштаб зображень, зміна станів.
Одна система анімації, без бібліотек. `prefers-reduced-motion` вимикає рух повністю,
контент лишається на місці.

## Структура файлів

```
index.html            весь контент (семантика, SEO, OG, JSON-LD, data-track)
css/style.css         токени, секції, адаптив, reduced-motion
js/main.js            вступ, поява, меню, послуги, паралакс, морфінг, форма, аналітика
assets/
  fonts/              Unbounded + Inter (woff2, latin + cyrillic) і fonts.css
  images/             фірмові 3D-об'єкти (webp з прозорістю), лого, og-image
  images/source/      PNG-майстри (не використовуються сайтом)
  icons/favicon.svg
```

## Що замінити перед публікацією

- [ ] **Адреса сайту** — `https://bbastiuk.github.io/sodo-agency/` у `<link rel="canonical">`,
      `og:url` і в JSON-LD.
- [ ] **Контакти.** Зараз у коді: Telegram `t.me/sodoagency` (як у шапці Instagram),
      Instagram `instagram.com/sodo.agency`, пошта `hello@sodo.agency`.
      Пошту перевірте — вона не підтверджена.
- [ ] **Форма.** У `js/main.js` впишіть `FORM_ENDPOINT` (напр. Formspree
      `https://formspree.io/f/xxxxxxx`). Поки поле порожнє, сайт **не вдає успішну
      відправку**: після валідації він показує повідомлення, що форму ще не підключено,
      і дає готовий лист (`mailto` з підставленим текстом) та Telegram.
      `FALLBACK_EMAIL` і `FALLBACK_TG` — там само.
- [ ] **Кейси** (у `index.html`, секція «роботи»):
      - `Street Barbershop` — містить лише публічні показники профілю Booksy
        з відповідною приміткою.
      - `FORMAI`, `LegalizuYou`, `MS West` — позначені плашкою «дані заповнити»,
        у рядку «результат» стоять «—». Впишіть реальні цифри або приберіть картку.
      - Опис задачі та робіт — теж шаблонний, перепишіть під факти.
- [ ] **Зображення кейсів.** Зараз це фірмові 3D-об'єкти з підписом
      «демо-візуал · замінити на матеріали кейсу». Замініть на реальні матеріали
      (рекомендація: ч/б кадри з рожевими деталями, великий кроп).
- [ ] **Фото команди** — у секції «про нас» два пунктирні плейсхолдери
      (`.ph__box`). Вставте `<img>` замість `<div class="ph__box">`; формат 3:4, ч/б.
- [ ] **OG-зображення** `assets/images/og-image.jpg` — замініть на фірмове 1200×630.
- [ ] **Аналітика.** Події вже пишуться у `window.dataLayer` з префіксом `sodo_`
      (`sodo_hero_contact`, `sodo_service_open`, `sodo_form_submit`, `sodo_lead` тощо).
      Додайте свій сніпет GTM / GA4 / Meta Pixel у `<head>` — жодних чужих ID у коді немає.

## Доступність і продуктивність

- Семантичні секції, один `h1`, послідовні заголовки, skip-link, видимий фокус.
- Послуги — це `<button aria-expanded>` з панеллю: працюють з клавіатури й на дотик;
  наведення мишею лише пришвидшує те, що й так доступне кліком.
- Жодна інформація не сховна тільки за hover.
- Форма: `<label>` для кожного поля, помилки через `aria-describedby` + `aria-invalid`,
  статус у `role="status"`.
- Без горизонтального скролу від 320px до 1920px (перевірено).
- Шрифти — локальні woff2 із `preload` для кирилиці (~150 КБ разом),
  зображення — webp із `loading="lazy"` нижче першого екрана.

## Локальний запуск

```
python -m http.server 8080
```
і відкрити `http://127.0.0.1:8080/`. Відкривати `index.html` подвійним кліком теж можна,
але локальні шрифти краще перевіряти через сервер.
