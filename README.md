# SODO

Сайт digital-агенції SODO. Одна сторінка, статичний HTML + CSS +
ванільний JS. Без збірки, без залежностей, без CDN.

```bash
python -m http.server 8080
# http://127.0.0.1:8080
```

Живий: https://www.sodoagency.eu (Vercel; `sodoagency.eu` без www переадресовує сюди)

---

## Як влаштовано

```
index.html          уся розмітка, українською; en і pl підставляються з lang/
css/style.css       усі стилі
js/main.js          увесь скрипт, один IIFE, без модулів
api/lead.js         серверлес-функція Vercel: заявка з форми -> Telegram
lang/{uk,en,pl}.json
assets/fonts/       woff2 + fonts.css
assets/figures/     силует у героєві
assets/icons/       favicon, вордмарк
assets/images/      og-image, apple-touch-icon
```

Українська лежить прямо в розмітці — це джерело. `lang/uk.json` тримає
лише ті рядки, яких у розмітці немає (мітки для читачів екрана,
подвійні стани кнопок). `en.json` і `pl.json` повні.

Мова обирається так: `?lang=`, далі `utm_source`/`utm_campaign`, далі
мова браузера, далі `uk`. Вибір лишається в `localStorage`.

## Заявки

Форма шле POST на `/api/lead`. Функція перевіряє склад, екранує HTML і
переказує в Telegram. Токен бота живе у змінних середовища Vercel:

```
TG_TOKEN   токен від BotFather
TG_CHAT    chat_id, куди слати
```

У репозиторії їх немає і бути не повинно: сайт статичний, усе, що в
ньому лежить, видно через «переглянути код».

Екран подяки показується **тільки** після `r.ok`. Якщо відправка не
вдалась, форма лишається заповненою й показує, куди написати. Якщо
`FORM_ENDPOINT` колись спорожнити, працює запасний шлях — поля в буфер
і відкритий Telegram, — але й там «дякуємо» зʼявляється лише коли
вкладка справді відкрилась.

Приховане поле `company` — пастка для автоматів. Заповнене — відповідаємо
успіхом і нікуди не шлемо.

## Кольори

```
--bg          #F2F1EE   тло
--card        #FBFAF8   світла площина
--ink         #161514   найтемніше; чистого чорного немає ніде
--pink        #FA9BB6   фірмовий, рівно один
--pink-soft   #FFD9E4   другий тон того ж кольору, тільки під маркер
--ink-muted   #5E5C58   5.91:1 на --bg
--ink-muted-inv #A8A5A0 7.43:1 на --ink
```

Рожевий один і без винятків. Глибина там, де вона потрібна (активна
плитка), робиться світлом і тінню поверх нього, а не іншими рожевими.
Білий на рожевому дає 1.93:1, тому текст на рожевому — завжди `--ink`.
Де потрібен світлий текст, площина чорна, а не рожева.

## Типографіка

```
--display   Montserrat   H1/H2 капсом, назви, великі цифри
--text      Onest        увесь основний текст і H3
--ui        Pixelify     мітки, але тільки з літер
--num       Onest        номери, лічильники, роки
```

**Pixelify не набирає цифр.** У ньому 2 і 5 на дрібному кеглі читаються
як S: «02» виходить «0S». Усе, де є числа, йде `--num` з розрядкою і
`tabular-nums` — характер мітки тримають капс і трекінг, а не шрифт.

Радіуси: 4 / 6 / 8 для дрібного, 12 для плиток і карток.

## Поле сторінки

`--gut` — поля з боків. До 1473px це `clamp(18px,3.4vw,56px)`, вище —
`(100vw - 1360px)/2`, тож зміст стає колонкою 1360 по центру й не
розповзається на широкій панелі.

Від 1024px «5 кроків» і цикл SODO стоять колонками в ряд, а не списком
униз. Форма від 1100px — у три колонки, FAQ від 1024 — тема ліворуч,
питання праворуч.

## Рух

Одна мова: тільки прозорість і зсув, ніякого пружинення.

**Заставка** (`boot()`) — не таймер, а нижня межа 880 мс. Смуга внизу
показує менше з двох: скільки роботи справді зроблено (шрифти, переклад,
силует) і скільки минуло від цієї межі. На швидкому зʼєднанні вона не
стрибає в кінець, на повільному не бреше. Повторний захід у тій самій
вкладці — 240 мс (`sessionStorage`).

**Прогрес у процесах** веде прокрутка, не таймер. Рейка знає свою вісь:
вертикально до 1024px, горизонтально вище. Мірка обирає вісь за класом
`is-row`, який вішає JS — тому без скриптів лишається вертикальна
розкладка, яка працює сама по собі.

**Послуги.** Поки людина нічого не натиснула, всі шість плиток
нейтральні і чорної картки немає взагалі. Вибір робить людина, не сайт.

## Без JS і зі зменшеним рухом

Обидва стани опрацьовані повністю, не формально.

`<noscript>` у `index.html`: заставка знята, усе, що зʼявляється при
прокрутці, показане одразу, відповіді FAQ розгорнуті, усі шість карток
послуг показані підряд (бо вибору без JS не існує), примітки про ціни
видно.

`prefers-reduced-motion`: переходи зведені до 0.01 мс, кроки й цикл
позначені пройденими одразу, рейки залиті на всю довжину по своїй осі,
заставка просто знімається.

Перевіряти обидва після будь-якої зміни в секціях, що живуть від
прокрутки, — саме там їх найлегше зламати непомітно.

## Доступність

- переходи мовою через `<a href="?lang=">`, працюють без JS
- таби послуг — `role="tablist"` з роверним `tabindex`, стрілки водять
- FAQ — `aria-expanded` + `aria-controls`, висота анімується, не `display`
- помилки форми стоять під своїм полем із `role="alert"`, а не однією
  на всю форму
- усі клікабельні цілі від 44px
